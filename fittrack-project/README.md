# FitTrack - Fitness Challenge Platform 🏋️‍♀️

A comprehensive responsive web application for tracking fitness challenges, workouts, and progress. Built as a complete learning project to demonstrate modern responsive web design techniques.

## 🎯 Purpose

This project is designed as a **complete practice project for learning responsive web design**. It demonstrates:

-   ✅ **Flexbox** - Navigation bars, button groups, stats displays
-   ✅ **CSS Grid** - Challenge cards, dashboard layouts, feature sections
-   ✅ **Media Queries** - Mobile-first responsive breakpoints
-   ✅ **Container Queries** - Component-level responsive design
-   ✅ **Modern UI** - Built with React, TypeScript, and Tailwind CSS 4

## 🚀 Features

-   **Landing Page** with responsive hero section
-   **Challenge Cards** that adapt to container width
-   **Dashboard** with statistics and progress tracking
-   **Workout Tracker** for logging exercises
-   **Leaderboard** to view rankings
-   **Profile Page** for user information
-   **Fully Responsive** - Works on mobile, tablet, and desktop

## 📱 Responsive Breakpoints

-   **Mobile**: < 640px (sm)
-   **Tablet**: 640px - 768px (md)
-   **Desktop**: 768px - 1024px (lg)
-   **Large Desktop**: > 1024px (xl)

## 🎨 Key Learning Points

1. **Mobile-First Approach** - Base styles for mobile, enhanced for larger screens
2. **Semantic HTML** - Proper use of semantic tags
3. **Component Reusability** - DRY principles throughout
4. **Interactive States** - Hover effects and transitions
5. **Accessibility** - Keyboard navigation and proper ARIA labels
